# Plan: Folder Nesting, Note Cards with Screenshots, and Fixed Backup

This plan addresses the requirements for deep folder nesting, note cards with "last viewed" screenshots, and fixing the backup functionality.

## 1. Deep Folder Nesting & UI Rework
- **Recursive Move Logic:** Update `FolderNotifier` to support moving folders and notes into any folder of the same type (Subject/Note), regardless of depth.
- **Tree-Structured Destination Selection:** Implement a new `FolderSelectionTree` widget that displays the folder hierarchy for moving items.
  - **Unified Approach:** The `FolderSelectionTree` will always show the full hierarchy without filtering out any folders based on `excludeFolderId`. Instead, the widget will handle exclusion logic through UI interaction:
    - For **moving folders**: The folder being moved (`excludeFolderId`) will be displayed but disabled (non-interactive) in the tree.
    - For **moving notes**: The current folder (where the note is located) will be displayed, highlighted as the current location, and disabled as a direct destination, but its subfolders will remain interactive and selectable.
  - This ensures users can always see and navigate the complete folder hierarchy, including subfolders of the current folder, while preventing invalid move operations.
- **Folder List Unification:** Rework `SubjectScreen` to use a common `EntityGrid` that handles both folders and notes/exercise lists with consistent styling.

## 2. Note Cards with Screenshots
- **Last Viewed Screenshot Capture:** 
    - In `NoteScreen`, use a `RepaintBoundary` around the canvas.
    - Before exiting or on save, capture the current viewport as a PNG.
    - Save this PNG to a local path associated with the `Note` model.
- **Card-style Note Items:**
    - Replace `ListTile` in `SubjectScreen` with a `NoteCard` widget.
    - `NoteCard` size will be approximately 1/2 the size of a `FolderCard`.
    - Display the captured screenshot in the card.
    - Add a label at the bottom with the note name.
    - Include a "3 dots" menu button with Move, Rename, and Delete options.

## 3. Fixed Backup (Export to Zip)
- **Main Thread Export (Revert):**
    - Revert the backup export to run in the main thread instead of using isolates.
    - The isolate-based approach caused issues with creating only 22B zip files.
    - The export will run synchronously in the main thread to ensure reliability.

## 4. Architectural Unification
- Create a `MoveEntityDialog` that uses the tree structure for both folders and notes.
- Ensure `FolderNotifier` has clear, unified methods for moving any "Entity" (Folder, Note, ExerciseList).

## Proposed Changes

### Models
- `Note`: Ensure `screenshotPath` is consistently used for the "last viewed" capture.

### Services
- `ExportService`: Revert `exportToZip` to run in the main thread.
- `StorageService`: Add helper for saving screenshots.

### Providers
- `FolderProvider`: 
    - Add `moveNote(String sourceFolderId, String targetFolderId, String noteId)`
    - Add `moveExerciseList(...)` if needed, or unify.

### Widgets
- `NoteCard`: New widget for the 1/2 size note cards.
- `FolderSelectionTree`: New widget for the tree-based move destination selection. **Important Fix:** Remove `f.id != excludeFolderId` from the filtering logic in `_buildTree` and instead disable interaction for excluded folders in the UI to prevent hiding their children.
- `SubjectScreen`: Significant rework to handle the new grid layout and unified architecture.

### Screens
- `NoteScreen`: Implement the screenshot capture logic on exit/save.
